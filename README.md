# InsafAI - AI Legal Aid for Public Services
### Youth AI4SDGs Impact Challenge 2027 Submission

**Problem:** 80% of citizens in Pakistan don't know their legal rights or how to access public services.

**Solution:** InsafAI is a FastAPI backend that uses AI to:
- Explain legal rights in simple Urdu/English
- Draft RTI, complaint, and application letters
- Guide users to relevant SDG: SDG 16 (Justice) & SDG 10 (Reduced Inequalities)

**Tech Stack:** FastAPI, Python, OpenAI compatible API
**Team:** ry14861-max / Adv. Rana M. Sarwar

**Run locally:**
pip install -r requirements.txt
uvicorn main:app --reload
